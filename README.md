# Job Portal

A full-stack Job Portal web application built with **Python, Django, HTML5, CSS3 and MySQL**. The platform features role-based workflows for Job Seekers and Employers, offering a complete solution for job postings, resume handling, and application tracking.

---

## 🚀 Features

- **Custom User Model:** Role-based authentication specifically tailored for Job Seekers and Employers.
- **Dynamic Dashboards:** Personalized views and control panels based on user roles.
- **Job Management:** Complete workflow for employers to post, edit, and close job vacancies.
- **Resume System:** Job seekers can upload resumes (PDF/Doc), and employers can view and download them directly.
- **Status Tracking:** Real-time application management system with status tracking (Pending, Shortlisted, Rejected).
- **View Security:** Protected routes using Django login decorators and mixins to prevent unauthorized access.
- **Responsive Frontend:** Clean and responsive user interface built using vanilla HTML5, CSS3, and Django Templates.
- **Production Ready:** Fully deployed with optimized settings for handling static and media files.

---

## 🛠️ Tech Stack

- **Backend:** Python, Django (MVC Architecture)
- **Database:** MySQL
- **Frontend:** Django Templates, HTML5, CSS3
